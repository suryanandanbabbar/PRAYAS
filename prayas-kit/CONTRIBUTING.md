# Contributing to prayas-kit

First off, thanks for taking the time to contribute!

## Development Setup

1. Fork and clone the repository.
2. Run `npm install` to install dependencies.
3. Make your changes in the `src/` directory.
4. Add or update tests in the `tests/` directory.
5. Run `npm run test` to verify changes.
6. Run `npm run lint` to ensure code style is maintained.
7. Run `npm run build` to verify tree-shaking and types.

## Pull Requests
- Please provide a detailed description of your changes.
- Ensure all CI checks pass.
