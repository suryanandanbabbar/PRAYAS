# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `prayas-kit`, please send an e-mail to the maintainer or open an issue if it is safe to disclose. All security vulnerabilities will be promptly addressed.
